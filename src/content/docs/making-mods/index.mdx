A [mod project](/making-mods/mod-projects/) is a directory with a `mod.config.json` and one or
more content layers. You author it, check it, then pack it into a file that anyone can install.
This section documents the project format itself, which two tools work on:

- **[LTK Editor](/editor/)**, the mod editor in LTK Manager. Start here if you are new to making
  mods. Its pages cover each step in the app.
- **[The `league-mod` CLI](/making-mods/command-line/)**, the same workflow from a terminal, for
  scripting, CI and batch work.

Projects are interchangeable between them. Nothing you build in one is locked away from the other.

## Before you start

Know what the game files you edit are. Read these two pages first:

- **[How Modding Works](/start-here/how-modding-works/)** - how your files end up
  in the running game.
- **[WAD Archives](/reference/file-formats/wad/)** - the container almost
  everything lives in.

The rest of the [format reference](/reference/file-formats/wad/) covers meshes,
skeletons, animations, textures, and property bins as you need them.
