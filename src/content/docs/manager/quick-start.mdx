This quick start takes you from nothing installed to a game of League with your first mod. It
takes about ten minutes.

<Screenshot
  file="manager/quick-start-result.webp"
  alt="Mods page with one mod turned on and the status bar showing Patcher running"
/>

## Prerequisites

- Windows 10 or later, 64-bit
- League of Legends, installed and updated
- A mod file that ends in `.fantome`, `.modpkg` or `.zip`. See
  [Where to find mods](/start-here/finding-mods/).

A <Hint as="span" tip="A file that changes how something in League looks or sounds." client:visible>[mod](/glossary/)</Hint> changes how something in League looks or sounds, for example a champion skin. Mods change only what
you see. Other players see the normal game.

## 1. Install LTK Manager

<DownloadButton>Download LTK Manager</DownloadButton>

1. Select **Download LTK Manager**. Your browser downloads `LTK.Manager_x64-setup.exe`, the
   installer for the newest version.
2. Open the file you downloaded and follow the installer.
3. Open LTK Manager from the Start menu.

:::note[If the download does not start]
Open the [LTK Manager release page](https://github.com/LeagueToolkit/ltk-manager/releases/latest).
Scroll down to **Assets** and select the file that ends in `x64-setup.exe`. Do not download the
other files: `latest.json`, the `.sig` file and the source code are for developers.

<Screenshot
  file="manager/quick-start-download.webp"
  alt="Assets list of an LTK Manager release on GitHub, with the x64-setup.exe file highlighted"
/>

:::

LTK Manager finds your League installation itself.

## 2. Add a mod

1. Select **Mods** in the title bar.
2. Drag your mod file from File Explorer onto the LTK Manager window.

   The mod appears at the top of your library. It is turned on.

You can also select **Import** in the toolbar and choose the file. See
[Install mods](/manager/library/install-mods/) for more ways to add mods.

## 3. Play with the mod

LTK Manager loads your mods with the <Hint as="span" tip="The part of LTK Manager that loads your enabled mods into League while you play." client:visible>[patcher](/glossary/)</Hint>. The patcher must run before League starts a game.

1. Select **Start** in the toolbar.

   The status bar shows **Patcher running**. The first start can take a few minutes, because LTK
   Manager prepares a copy of the game files your mod changes.

2. Open League from the Riot Client as you usually do, and start a game.

   Your mod shows in game.

3. When you are done playing, select **Stop Patcher**.

<Screenshot file="manager/quick-start-start.webp" alt="Mods page toolbar with the Start button" />

:::caution
Stop the patcher before you change your mods. LTK Manager does not let you turn mods on or off,
install mods or switch profiles while the patcher runs.
:::

If the mod does not show in game, see [Troubleshooting](/manager/troubleshooting/).
