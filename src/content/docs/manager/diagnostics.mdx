When a game with mods has a problem, for example a crash or a stop on the loading screen, LTK
Manager records an incident. Diagnostics lists these incidents and tells you what went wrong, which
mod is the likely cause, and what to do next.

To open Diagnostics, press <kbd>Ctrl</kbd>+<kbd>D</kbd> or select the diagnostics button in the
title bar. On the Home page, **Review** in the Last game tile opens the incident
for your most recent game.

## Incident list

Each row shows the verdict, the time, the profile and how long the game ran. The mark before the
verdict tells you how serious it is: a triangle for a problem, a circle for information. A selected
incident is highlighted.

Examples of verdicts are **Unexplained Game Exit**, **Loading Screen Stall**, **Missing Game
Data** and **Skinhack Detection**.

## Skinhack detection

Before the game loads your mods, the patcher scans them for a skinhack: an official Riot skin put
onto a base champion. When the scan finds one, the patcher stops, and no mods are applied for that
game. The incident shows **Skinhack detection triggered** and **No mod ran**.

- The verdict names the game file that the scan rejected, such as `graves.wad.client`.
- **Suspects** names the mod that writes that file.
- To play with your other mods, turn off the mod that the scan named, then start the patcher
  again.

See [Mods that LTK Manager blocks](/manager/library/#mods-that-ltk-manager-blocks).
