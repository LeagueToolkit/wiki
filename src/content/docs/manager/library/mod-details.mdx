The details panel shows everything about one mod: what it is, who made it, which game files it
changes, its readme and its license. You can also edit the name, tags and image that the library
shows for the mod.

## Open the details panel

1. Right-click the mod, or select its menu button.
2. Select **Details** or **Readme**.

   The panel opens over the right side of the grid, on the tab you chose.

To close the panel, select its close button. To open it again on the same mod, select
**Documents** in the toolbar. Drag the left edge of the panel to change its width.

## Read the Details tab

The **Details** tab shows the mod's image, name, version, authors, install date, description and
tags.

## Read the readme and license

- **Readme** shows the readme file the author included. It shows **No readme** when there is none.
- **Licenses** shows the license the author chose, and its text when the mod includes it. It shows
  **No license declared** when the author chose none.

When a tab shows **Readme unreadable**, LTK Manager cannot read the mod's file. The mod may not
work. Install it again.

## Edit a mod's details

1. On the **Details** tab, select **Edit**.
2. Change any of these:
   - **Mod Name**
   - **Tags** and **Maps**
   - **Champions**, as a comma-separated list
   - The image: select **Set thumbnail** or **Remove thumbnail**
3. Select **Save**.

   LTK Manager shows **Metadata updated**.

Under **Auto-detected suggestions**, LTK Manager suggests tags, maps and champions from the mod's
files. Select a suggestion to add it, or select **Apply all**.

Your changes apply only to your library. They do not change the mod file.
