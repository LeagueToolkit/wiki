The mod library is the set of mods you installed in LTK Manager. You see and manage it on the
**Mods** page. To open it, select **Mods** in the title bar or press <kbd>Ctrl</kbd>+<kbd>2</kbd>.

## Installed and turned on

An installed mod is in your library, but it loads in game only when it is turned on. Turn off a
mod to keep it for later without uninstalling it. When you start the <Hint as="span" tip="The part of LTK Manager that loads your enabled mods into League while you play." client:visible>[patcher](/glossary/)</Hint>, it loads every mod that is turned on.

The library keeps a copy of each mod file. You can delete the file you downloaded after you
install it.

## Load order

Two mods can change the same game file, for example two skins for the same champion. Only one of
them can show in game. The **load order** decides which one: **the mod higher in the list wins**.

The load order is the order the library shows when **Sort by** is **Priority**, which is the
default. A mod you install goes to the top. See
[Change the load order](/manager/library/load-order/).

## Folders

A folder groups mods, for example all your ward skins. You can turn every mod in a folder on or
off at once. Folders are one level deep, so a folder cannot hold another folder. Every profile
shows the same folders. See [Organize mods into folders](/manager/library/folders/).

## Profiles

A <Hint as="span" tip="A saved set of enabled mods and their load order." client:visible>[profile](/glossary/)</Hint> is a saved set of the mods that are turned on. Each profile has its own mods on and off, and its own
load order. All profiles share the same installed mods and the same folders.

Use profiles to switch between setups, for example one for ranked games and one with every mod.
The profile named **Default** always exists. See [Manage profiles](/manager/library/profiles/).

## Mod health

LTK Manager can check your mods for problems, such as files that no longer match the current
version of League. It repairs what it can. See
[Check and repair mods](/manager/library/mod-health/).

## Mods that LTK Manager blocks

LTK Manager does not load a skinhack, which is a mod that gives access to paid League skins. A
skinhack shows dimmed in the library and you cannot turn it on. Select **What is a skinhack?** in
its menu to read why.

:::danger
Using a skinhack breaks Riot's rules and can put your account at risk.
:::

If you think LTK Manager blocked a mod by mistake, open an issue on the
[LTK Manager repository](https://github.com/LeagueToolkit/ltk-manager/issues).

## Changes while the patcher runs

You can change your library while the patcher runs. When you turn mods on or off, change the load
order, install, update or uninstall mods, or switch profiles, the change applies to your next game.

- **No game is open.** LTK Manager rebuilds the overlay a moment after your last change. Several
  changes in a row cost one rebuild.
- **A game is open.** The change waits, and **Applies after this game** shows next to **Stop
  Patcher**. LTK Manager rebuilds the overlay when the game closes.

A change never reaches a game that is already running. A game that starts during the few seconds of
a rebuild runs without mods.

Two changes still need the patcher stopped: repairing a mod and renaming a profile.
