A folder groups mods, for example all your ward skins or all mods for one champion. You can turn
every mod in a folder on or off at once. All profiles share the same folders, but each profile
keeps its own mods on and off.

## Create a folder

1. Right-click an empty area of the Mods page.
2. Select **New Folder**.
3. Enter a name, then select **Create**.

   The folder appears in the library.

## Move a mod into a folder

- Drag the mod's card onto the folder.

The mod goes to the end of the folder. A mod can be in one folder only.

## Move a mod out of a folder

- Right-click the mod, or select its menu button, then select **Remove from folder**.

You can also drag the mod onto **Drop here to remove from folder**, which shows at the bottom of
the page while you drag a mod from a folder.

## Open a folder

- In the grid view, select the folder card. To go back, select the back arrow.
- In the list view, select the folder row. It opens in place.

## Turn a folder on or off

- Select the checkbox on the folder, or right-click it and select **Enable All** or
  **Disable All**.

See [Turn mods on and off](/manager/library/enable-mods/#turn-a-folder-on-or-off).

## Rename a folder

1. Right-click the folder and select **Rename**.
2. Enter the new name, then select **Rename**.

## Delete a folder

- Right-click the folder and select **Delete**.

The folder is deleted at once. Its mods stay installed and move out of the folder.

## Limitations

- A folder cannot hold another folder.
- You cannot move several selected mods into a folder at once.
