A profile is a saved set of the mods that are turned on, with its own load order. Switch profiles
to change which mods load, without turning each mod on or off. All profiles share the same
installed mods and folders.

The profile selector is in the toolbar of the Mods page. It shows the name of the active profile.

## Create a profile

1. Select the profile selector.
2. Select **New Profile**.
3. Enter a name, then press <kbd>Enter</kbd>.

   LTK Manager shows **Profile created**.

A new profile starts with every mod turned off.

## Switch profiles

1. Stop the patcher.
2. Select the profile selector.
3. Select the profile you want.

   The mods that are on change to the ones saved in that profile.

## Rename a profile

1. Stop the patcher.
2. Select the profile selector.
3. Select the pencil next to the profile.
4. Enter the new name, then press <kbd>Enter</kbd>.

You cannot rename the **Default** profile.

## Delete a profile

1. Select the profile selector.
2. Select the trash can next to the profile.
3. Select **Delete Profile** to confirm.

Deleting a profile does not uninstall any mods. You cannot delete the **Default** profile or the
active profile. To delete the active profile, switch to another profile first.
