When your library grows, search, filters and sorting help you find a mod. They change only what
the Mods page shows. They do not change the load order.

## Search by name

1. Select the **Search mods...** box in the toolbar, or press <kbd>Ctrl</kbd>+<kbd>F</kbd>.
2. Enter part of the mod's name.

While you search, the page shows matching mods from all folders in one list. To show all mods
again, clear the search box.

## Filter by champion, tag or map

1. Select the funnel in the search box.
2. Select the values you want under **Champion**, **Tags** or **Maps**.

   The mods that match show. The active filters show as chips under the toolbar.

A mod matches when it has any of the values you selected in a column. When you select values in
two columns, a mod must match both. For example, **Ahri** and **Summoner's Rift** shows only Ahri
mods for Summoner's Rift.

To remove one filter, select the **x** on its chip. To remove all filters, select **Clear all**.

The champions, tags and maps come from the mod's author and from what LTK Manager detects in the
mod's files. To detect them for mods that have none, select **Analyze** in the toolbar.

## Sort the library

1. Select the funnel in the search box.
2. Under **Sort by**, select one of these:

   <dl>
     <dt id="sort-priority">Priority</dt>
     <dd>
       The load order. This is the default, and the only sort in which you can drag mods to reorder
       them.
     </dd>
     <dt id="sort-name">Name</dt>
     <dd>By name, **A–Z** or **Z–A**.</dd>
     <dt id="sort-champion">Champion</dt>
     <dd>By champion name. Mods with no champion go last.</dd>
     <dt id="sort-date">Date Added</dt>
     <dd>By install date, **Newest** or **Oldest**.</dd>
     <dt id="sort-enabled">Enabled</dt>
     <dd>Mods that are on come first.</dd>
   </dl>

To reverse the direction, select the same option again.

## Change how mods show

- Select the grid or list button in the toolbar to change the view.
- Select **View options** next to it to change **Card size**, or to show or hide **Tags** on cards.

LTK Manager keeps these choices when you restart it.
