Uninstall a mod to delete it from your library and from every profile. To stop using a mod but
keep it, turn it off instead. See [Turn mods on and off](/manager/library/enable-mods/).

## Prerequisites

- The patcher is stopped.

## Uninstall one mod

1. Right-click the mod, or select its menu button.
2. Select **Uninstall**.

:::caution
**Uninstall** in the mod's menu deletes the mod at once, with no confirmation. To use the mod again,
you must install it again from its original file.
:::

## Uninstall several mods

1. Select the mods. See [Select several mods](/manager/library/select-mods/).
2. In the selection bar, select **Uninstall _n_**.

   A window lists the mods to be removed.

3. Select **Uninstall _n_ mods** to confirm.

   LTK Manager shows **Mods uninstalled**. If some mods could not be removed, they stay selected, so
   you can try again.
