A health check looks for problems in your mods, for example files made for an older version of
League. LTK Manager repairs many of these problems itself. Check your mods after a League patch,
or when a mod does not show in game.

## Prerequisites

- The hashtables are downloaded. The check needs these files to read mods. If **Check health** says
  the hashtables are not synced, sync them in [Settings](/manager/settings/).

:::caution
A health check finds known problems in a mod's files. It cannot prove that a mod works in game. A
mod with no problems found can still crash the game or show wrong. After a League patch, always try
your mods in a Practice Tool or custom game before you play a real match.
:::

## Check your mods

Do one of these:

- To check every mod, select **Check health** in the toolbar of the Mods page.
- To check some mods, select them, then select **Check health _n_** in the selection bar.
- To check one `.fantome` mod, right-click it and select **Check Health**.
- On the Home page, select **Health status** when it reads **Healthy** or **Not checked**.

When the check finds no problems, LTK Manager shows **No problems found**.

## Read the results

When the check finds a broken mod, the **Detected issues with mods** window opens. For smaller
problems, LTK Manager shows a message instead. Select **Show me** in the message, or select the
health item in the status bar, to open the window. The window lists each mod and what the check
found.

<Screenshot

Each finding tells you what you can do:

- A **Repair** button: LTK Manager can fix the finding.
- **Not auto-fixable**: LTK Manager cannot fix the finding. The mod still loads, but part of it
  may not work.
- **Needs an updated version**: the mod does not work with the current version of League. Look for
  a new version from the mod's author.

Select **Info** to also show findings that are not faults.

A mod with a health problem shows a mark on its card. Point to the mark to see a summary of the
problem. Select the mark to check the mod again or to repair it.

/>

## Repair mods

1. Stop the patcher. A repair changes mod files that the patcher uses.
2. In the **Detected issues with mods** window, select one of these:
   - **Repair** on one mod's row. The button shows when you point to the row.
   - **Repair _n_ enabled mods** to repair the mods that are on
   - **Repair all _n_**, from the arrow next to the repair button, to repair every mod

   LTK Manager shows **Repaired _n_ mods** when it is done. To stop a repair, select the close
   button next to the progress.

<Screenshot
  file="manager/library-health-repair-row.webp"
  alt="A mod's row in the Detected issues with mods window, with the Repair button under the pointer"
/>

To repair one mod from its card, select the mark on the card, then select **Repair**.

<Screenshot
  file="manager/library-health-repair.webp"
  alt="Health popover on a mod card with This mod needs a repair, the check again button and the Repair button"
/>

On the Home page, when **Health status** reads **_n_ repairs**, select it to open the Mods page
with the repair ready.
