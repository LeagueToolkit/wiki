A mod loads in game only when it is turned on. Turn off a mod to keep it installed without using
it. The mods that are on are saved in your active profile.

## Prerequisites

- The patcher is stopped. You cannot turn mods on or off while it runs.

## Turn one mod on or off

- In the grid view, select the mod's card. A mod that is off shows dimmed.
- In the list view, select the switch on the right of the row, or select the row.

When the card has keyboard focus, you can also press <kbd>Enter</kbd> or <kbd>Space</kbd>.

## Turn a folder on or off

- Select the checkbox on the folder card or folder row.

If every mod in the folder is on, the checkbox turns them all off. Otherwise it turns them all on.
When some of the mods are on, the checkbox shows a dash. You can also right-click the folder and
select **Enable All** or **Disable All**.

## Turn every visible mod on or off

1. Select the arrow next to **Select all** in the toolbar.
2. Under **All visible**, select **Enable** or **Disable**.

This changes every mod the grid shows. To change only some mods, search or filter first. See
[Find a mod](/manager/library/find-mods/).

## Turn several mods on or off

1. Select the mods. See [Select several mods](/manager/library/select-mods/).
2. In the selection bar, select **Enable _n_** or **Disable _n_**.

The mods stay selected, so you can change them again.

## Choose a mod's layers

Some mods have more than one layer. A layer is a part of the mod you can turn on or off, for
example an extra sound pack. These mods show a layer count, such as **2/3**, on the card.

1. Select the layer count on the card.
2. Select the checkbox of each layer you want.

The **base** layer is always on.
