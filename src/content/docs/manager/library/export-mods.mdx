Export your mods to copy their files out of LTK Manager, for example to back them up or to move
them to another computer. Exporting does not change your library.

1. On the **Home** page, select **More library actions** in the **Your library** tile.
2. Select **Export mods**.
3. Under **What to export**, select **Everything** or **Enabled**.

   **Enabled** exports only the mods that are on in your active profile.

4. Under **As**, select **A folder** or **One .zip**.
5. Select **Export**, then choose where to save the mods.

   The tile shows **Exporting** while it runs. When it is done, LTK Manager shows
   **Exported _n_ mods**. Select **Show me** to open the folder.

Some mods have no file to export, for example a mod stored as a project. LTK Manager skips these
mods and tells you how many it skipped.
