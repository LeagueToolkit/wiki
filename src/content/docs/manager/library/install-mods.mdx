Install a mod to add it to your library. LTK Manager installs `.fantome`, `.modpkg` and `.zip`
mod files. A mod you install goes to the top of your library and is turned on in your active
profile.

## Prerequisites

- The patcher is stopped. LTK Manager does not install mods while the patcher runs.
- A mod file. See [Where to find mods](/start-here/finding-mods/).

## Drag and drop mod files

1. Open the **Mods** page or the **Home** page.
2. Drag one or more mod files from File Explorer onto the LTK Manager window.

   The window shows **Drop to install**.

3. Release the files.

LTK Manager ignores files of other types.

## Install from a file browser

1. On the **Mods** page, select **Import**, or press <kbd>Ctrl</kbd>+<kbd>I</kbd>. When the
   library is empty, you can also select **Import Mods** in the middle of the page. On the **Home**
   page, select **Add mod**.

   <Screenshot
     file="manager/library-empty.webp"
     alt="Empty Mods page with No mods installed, the Import button in the toolbar and the Import Mods button"
   />

2. Choose one or more mod files, then select **Open**.

When you install one mod, it appears in the library. When you install two or more, the
**Importing Mods...** window shows the progress. When it shows **Import Complete**, it lists the
mods that installed and the files that failed, with the reason. Select **Done** to close it.

:::note
If a mod is a skinhack, LTK Manager installs it but turns it off and shows **Skinhack Detected**.
See [Mod library](/manager/library/#mods-that-ltk-manager-blocks).
:::

## Update a mod

When the author releases a new version of a mod, update the mod to keep its place in your
library and its settings.

1. Right-click the mod, or select its menu button.
2. Select **Update from file**.
3. Choose the new mod file.

   LTK Manager shows **Mod updated**.

## Import mods from cslol-manager

If you used cslol-manager, you can copy its mods into LTK Manager. See
[Migrating from cslol](/start-here/from-cslol/).
