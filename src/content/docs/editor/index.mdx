LTK Editor is the part of LTK Manager where you make mods. It opens your League installation
directly, edits game files in a project, and tests and packs the result. Open it from **Workshop**
in the title bar of LTK Manager.

New to LTK Editor? Start with the [Quick start](/editor/quick-start/), then read
[Modding workflow](/editor/workflow/).
